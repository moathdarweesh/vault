# المرحلة الأولى: مركز الحفظ والمزامنة

الحالة: منفّذة محليًا، ولم تُنشر بعد. هذا توثيق المرحلة الأولى عند اكتمالها؛ تنفيذ المراحل اللاحقة في v311 موثق في `USER_CONVENIENCE_IMPLEMENTATION.md`. هذه المرحلة من خطة `USER_CONVENIENCE_ROADMAP_AR.md`.

## تجربة المستخدم

مركز واحد داخل الإعدادات يعرض حفظ السجلات على الجهاز وحالة مزامنتها بالسحابة. يميّز بين الانتظار، والمزامنة الجارية، وانقطاع الاتصال، والحاجة لتسجيل الدخول، والتعارض، وفشل الكتابة. يعرض إجراءً مناسبًا: إعادة المحاولة، مراجعة التعارض، تسجيل الدخول، أو تصدير نسخة عند تعذر الحفظ المحلي.

تاريخ النسخة السحابية يختلف عن وقت تأكيد المزامنة في الجلسة الحالية. ظهور نسخة قديمة لا يعني أن آخر تعديل محفوظ في السحابة. فشل الحفظ المحلي يتقدم على رسالة نجاح المزامنة.

## توزيع المسؤوليات

- `js/storage.js`: نتيجة الكتابة المحلية عبر `DB.saveState()`، مع الحفاظ على عقد `writeStore` المنطقي. لا تقرأ الواجهة التخزين مباشرة.
- `js/cloud.js`: تتبع العمليات ونتائجها لكل حساب عبر `Cloud.syncState()`، مع بقاء مؤشرات التعديل والإصدار الدائمة مصدر القرار.
- `js/app.js`: نموذج عرض مستقل `saveCenterModel` وتحديث محدود لعناصر المركز. تجميع الأحداث يمنع عرض نجاح محلي عابر قبل تسجيل التعديل السحابي.
- `styles.css`: تنسيق يستعمل ألوان ومقاسات التطبيق القائمة، قبل طبقة الهوية.

لا طلبات شبكة إضافية أو استطلاع دوري، ولا جداول جديدة أو تعديل SQL أو Worker أو اعتماد جديد للتطبيق.

## التحقق

```text
npm run check
npm run release:check
node scripts/test-sync-status.js
node scripts/test-plan-import.js
node scripts/test-sync-status-ui.js
```

اختبار الواجهة الاختياري يحتاج Playwright متاحًا من بيئة التطوير وChrome. يشغّل التطبيق الحقيقي على عنوان محلي بحساب وشبكة اصطناعيين، ويمنع الاتصالات الخارجية. يغطي العربية والإنجليزية، عرض هاتف 390px، حالات المزامنة، إعادة المحاولة، وفشل الحفظ. اختبار المنطق يغطي بقاء تعديل أحدث أثناء رفع سابق، تبديل الحساب، انتهاء الجلسة، التعارض وحله، وفحص الإصدار الخفيف.

## حدود المرحلة والخطوة التالية

- المركز يصف حفظ السجلات؛ لا يؤكد نسخ صور التمارين المنفصلة.
- لم تُحوَّل جميع عمليات الكتابة القديمة إلى معاملات تستعيد الذاكرة عند الفشل. هذه مسؤولية تنفيذ التراجع في المرحلة التالية.
- اختبارات الأعطال معزولة؛ لم تُنفذ أعطال متعمدة على حساب إنتاج حقيقي.
- ميزات التراجع والوجبات المتكررة والبحث وقائمة المشتريات لم تُنفذ ضمن هذه المرحلة.
