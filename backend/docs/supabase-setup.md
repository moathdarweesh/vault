# إعداد Supabase لتسجيل الدخول والمزامنة (THE VAULT)

الهدف: حساب (إيميل + كلمة سر) تتزامن بياناتك فيه بين كل أجهزتك. مجاني تماماً.

---

## 1) إنشاء مشروع Supabase

1. روح **https://supabase.com** → **Start your project** → سجّل دخول (بحساب GitHub أو إيميل).
2. اضغط **New project**.
   - **Name:** the-vault (أو أي اسم).
   - **Database Password:** اختر كلمة سر قوية واحفظها (ما رح تحتاجها كثير، بس احفظها).
   - **Region:** اختر الأقرب لك (مثلاً Frankfurt / Bahrain).
3. اضغط **Create new project** وانتظر ~دقيقتين لين يجهز.

---

## 2) إنشاء جدول البيانات

1. من القائمة اليسار → **SQL Editor** → **New query**.
2. افتح الملف `backend/migrations/01_supabase-setup.sql` وانسخ محتواه كامل والصقه.
3. اضغط **Run** (أو Ctrl+Enter). لازم يطلع **Success**.

---

## 3) (مهم للتجربة السريعة) إيقاف تأكيد الإيميل

افتراضياً Supabase يطلب تأكيد الإيميل قبل أول دخول. لتسهيل التجربة:

1. القائمة اليسار → **Authentication** → **Sign In / Providers** (أو **Providers**).
2. افتح **Email**.
3. أوقف خيار **Confirm email** (Disable) → **Save**.

> بعدها أي تسجيل جديد يدخل مباشرة بدون ما ينتظر إيميل تأكيد. (تقدر ترجّعه لاحقاً لو نشرت التطبيق لناس ثانية.)

---

## 4) نسخ الرابط والمفتاح

1. القائمة اليسار → **Project Settings** (الترس) → **API**.
2. انسخ:
   - **Project URL** — شكله: `https://xxxxxxxx.supabase.co`
   - **anon public** key — نص طويل يبدأ بـ `eyJ...`
3. أعطني القيمتين (أو حطّهم بنفسك في الملف `js/cloud.js` فوق):
   ```js
   const SUPABASE_URL = 'https://xxxxxxxx.supabase.co';
   const SUPABASE_ANON_KEY = 'eyJ...';
   ```

> **مفتاح `anon` عام وآمن** يكون داخل التطبيق — حماية البيانات تجي من Row Level Security (كل مستخدم يشوف صفّه فقط)، مش من إخفاء المفتاح.

---

## 5) تم!

بعد ما تنحط القيمتان وتنبني النسخة:
- أول ما تفتح التطبيق رح تطلع شاشة **تسجيل دخول / إنشاء حساب**.
- أنشئ حساب على الجوال → بياناتك الحالية ترتفع للحساب.
- سجّل دخول بنفس الحساب على اللابتوب → نفس البيانات تنزل.
- أي تعديل بعدها يتزامن تلقائياً.
- تسجيل الخروج من **الإعدادات → الحساب**.
